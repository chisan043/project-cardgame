# Card Art Assets

This directory contains runtime card visuals for the demo.

## Runtime

- `art/`
  - Formal card illustrations grouped by visual theme.
  - Runtime paths should stay under `assets/cards/art/<theme>/`.
  - A single illustration can be shared by multiple cards when the design intentionally reuses the visual.

- `frames/`
  - Runtime card frame assets grouped by role or neutral theme.

## Registry

- `card-art-registry.json`
  - Generated by `tools/build_asset_registries.mjs`.
  - Lists each formal runtime card illustration and the cards currently using it.
  - Keep this generated file in sync after card art, card pool, or starter deck changes.

## Source

- `assets/source/cards/art/`
  - PNG source counterparts for formal card illustrations.
  - Source files are not runtime entry points.

## Candidates

- `assets/candidates/cards/`
  - Review-only concept material.
  - Candidate files must be promoted into `assets/cards/art/<theme>/` before gameplay data references them.

Chinese display names remain in `src/data/cards.js`; asset paths should stay short ASCII paths.
