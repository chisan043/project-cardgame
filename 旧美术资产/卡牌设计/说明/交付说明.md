# 卡牌设计交付说明

本次根据 `美术需求文档.txt` 中的卡面与卡框要求，优先完成了可直接用于卡牌设计讨论与二次迭代的首批资产。

## 目录说明

- `插画原图`
  - 6 张角色技能卡插画原图，分别覆盖勇者战士、萝莉魔导士、精灵弓箭手各 2 张。
- `卡框UI`
  - 3 套卡框母版：`圣剑金红框`、`秘法紫金框`、`森灵翠金框`
  - 每套附带 1 张安全区模板，便于后续放标题、费用、正文。
- `套框预览`
  - 已将插画与对应卡框合成的卡面预览图，可直接用于方案评审。
- `文案安全区`
  - 在预览图上额外标出标题区、插画安全区、规则文字区，便于继续排版。
- `卡牌设计总览.png`
  - 6 张卡牌预览汇总图，适合快速总览整套方向。

## 视觉处理说明

- 卡框方向遵循文档中的老派奇幻 UI 关键词，使用深底色、暗金边框、宝石点缀。
- 插画优先保留 90 年代赛璐璐奇幻动画感，不使用现代玻璃 UI 或高亮描边。
- 预览图中的费用、类别与规则文字为占位示意，后续可直接替换为正式策划文案。
