## 后续建议拆分的资产

- 角色选择主界面底板
- 单角色卡窗框
- 角色卡选中态外框
- 职业标签底板
- 特性标签底板
- 选择按钮
- 返回/确认按钮
- 标题纹章或标题底板

## 风格要求

- 保留彩窗结构感
- 但整体要服从赛璐璐奇幻动画的平涂层次
- 让角色立绘始终是主视觉
- 装饰集中在边框、节点、徽章，不要压过角色本身
