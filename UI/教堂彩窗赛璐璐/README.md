# 教堂彩窗赛璐璐 UI 资产目录

这套目录用于承接《幻境残卷》的新 UI 方向：

- 教堂彩窗的结构语言
- 90 年代日式赛璐璐奇幻动画的平涂分层
- 更强的仪式感、辨识度与世界观统一性

## 当前方向图

- `概念图/01_教堂彩窗方向图.png`
  - 更偏教堂玻璃、黄铜骨架、珠宝色块的 UI 概念板
- `概念图/02_教堂彩窗_赛璐璐融合方向图.png`
  - 当前确认的大方向
  - 保留彩窗结构，但整体质感更贴近 OVA 时代赛璐璐奇幻动画

## 目录规划

- `角色选择/`
  - 角色选择界面的主框、角色卡窗框、选中态、职业标识底板
- `按钮/`
  - 主按钮、次按钮、确认/取消、结束回合按钮
- `战斗HUD/`
  - 战斗 HUD 将按概念图整体重做
  - 不再先做零散小件
- `面板/`
  - 通用信息面板、弹窗底板、图鉴/商店/事件详情板
- `图标样式/`
  - 状态徽章、黄铜托座、彩窗边饰等图标承托样式
