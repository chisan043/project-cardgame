# 地图 UI imagegen 无背景资产 v1

根据地图概念图生成的 imagegen 组件表，经绿幕抠透明后切分为可用 UI 资产。

## 说明

- `source/`：保留 imagegen 原始绿底图与整张透明组件表。
- `panels/`：区域铭牌、左侧图例面板、右侧详情/预览/文本面板。
- `buttons/`：蓝金行动按钮。
- `frames/`：主地图黄铜边框叠加层。
- `nodes/`：战斗、精英、商店、休整、奇遇、传送门、首领节点徽章。
- `overview/`：棋盘格总览图，仅用于确认透明效果。
